# Fixtures

Test pages are served from a local static web server during a run, so network
variance does not affect results and every run uses identical input.

Each fixture lives in its own folder with an `index.html`; it loads only files
from this folder or `_shared/` — no external requests.

The inputs for the PDF tools are in `inputs/` (see `inputs/SOURCE.md`): PDFs printed by headless Chromium
from the fixture pages with each page's real text, DOCX files with Microsoft Word's own PDF export, an
AcroForm made with PyMuPDF, and an invoice page with its EN 16931 Factur-X XML (from SelectPdf's e-invoice
sample). Built by `_tools/make_inputs.py`.

Shared assets — Bootstrap, Bootstrap Icons, Chart.js (MIT) and subsetted static
instances of Inter, Lora, JetBrains Mono, Noto Sans Arabic/SC/JP/KR/Devanagari/Thai
and Noto Color Emoji (SIL Open Font License) — live in `_shared/` with their licences, built by
`_tools/build_shared.py`. Every page sets its fonts explicitly, so no fixture
depends on the fonts installed on the machine.

`fixtures.json` lists the fixtures with their wait time, media type and the
content checks applied to every library's output.

## Rules

- No live URLs in fixtures. A frozen copy is saved once and versioned.
- Every third-party asset records its source and licence in a `SOURCE.md` file in
  the fixture folder.
- A fixture is never changed in place after results have been published with it;
  a changed fixture gets a new name.
